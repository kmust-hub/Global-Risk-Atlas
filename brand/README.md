# 环球风险图谱 Logo 方案

本目录包含六组原创矢量 Logo 方向：

1. `logo-01-meridian.svg`：经线脉冲
2. `logo-02-rift-a.svg`：风险断层
3. `logo-03-five-sector.svg`：五维风险盘
4. `logo-04-atlas-grid.svg`：立体图谱
5. `logo-05-signal-globe.svg`：市场脉冲球
6. `logo-06-risk-aperture.svg`：风险光圈

打开 `logo-options.html` 可以并排查看全部方案。

这些图形为原创概念，但无法仅凭设计保证全球法律意义上的绝对唯一。正式商用前应进行近似商标和图形检索。
