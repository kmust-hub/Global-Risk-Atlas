# 实时市场可视化

这是一个本地实时仪表板，在同一张图上显示：

- 中证红利指数蜡烛图（000922）
- 创业板指蜡烛图（399006）
- 中证红利 90 月线和 40 月线
- 独立的 R 比价面板

## 启动

双击 `start.cmd`，浏览器会打开：

`http://127.0.0.1:8787`

停止服务可以运行 `stop.ps1`。

## 图表口径

- 上方为红利 K 线及 90/40 月线，中间为创业板指 K 线，下方独立显示 R。
- 红涨绿跌；1 年内使用日 K，3—5 年自动聚合为周 K，10 年及全历史使用月 K，移动端 1 年自动切换周 K。
- R 面板保留 0.33、0.52、0.65 三条策略参考线。
- 90 月线和 40 月线使用历史月收盘价计算，并把当前交易日的价格作为当月暂定收盘动态更新。
- 交易时段每 10 秒刷新报价；非交易时段每 5 分钟检查一次。
- 盘中新增的当天数据点是暂定值，正式日线应在收盘后确认。

## 数据来源

- 实时/收盘报价：东方财富移动行情页
- 指数完整历史：`../exports/combined_R_MA90_MA40_daily.csv`\n- 最近交易日更新：腾讯公开行情

“全历史”区间覆盖 2010-06-01 至最新共同交易日。服务优先读取本地完整历史文件，再合并腾讯最近日线；盘中报价继续使用东方财富。

## 文件结构

- `server.mjs`：本地数据服务，负责抓取、缓存和计算
- `index.html` / `styles.css` / `app.js`：前端图表
- `data/initial-data.json`：完整数据文件不可用时的静态回退数据\n- `../exports/combined_R_MA90_MA40_daily.csv`：完整历史与均线数据
- `vendor/d3.min.js`：本地 D3 图表库

本工具仅用于策略参数观察和可视化，不构成投资建议。
